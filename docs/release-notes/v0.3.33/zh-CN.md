## 新增

- 新增隐私模式，可在侧栏开启，遮蔽页面中的账号邮箱、账号 ID 和项目 ID，并记住开关状态；仅影响显示，不改变请求、搜索、复制或导出内容。
- “服务与访问”新增 GitHub 访问令牌设置，支持隐藏／显示令牌和跳转创建令牌；插件商店遇到 GitHub API 限流时可直接跳转配置。
- “模型与请求”新增“启用冷却”开关；缺少冷却配置时默认关闭，已有明确设置保持不变。

## 优化

- OAuth 登录卡片展示已保存的账号、数量及停用状态，支持跳转凭证文件查看；授权成功后自动刷新账号列表，方便管理多个账号。
- 将“重试与冷却”设置移至“模型与请求”，同步调整设置搜索定位和宽屏布局。
- 配套 CLIProxyAPI 内核升级至 v8.0.24。

## 修复

- 修正 OAuth 授权提示，明确添加新账号与重新登录已有账号的区别；重新登录会更新该账号凭据，不再提示每次授权都会新增账号。
- 修复启动时冷却配置可能被旧的界面配置或模板默认值覆盖的问题，保留用户明确开启或关闭的选择。
