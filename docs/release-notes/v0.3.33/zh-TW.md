## 新增

- 新增隱私模式，可在側欄開啟，遮蔽頁面中的帳號電子郵件、帳號 ID 與專案 ID，並記住開關狀態；僅影響顯示，不改變請求、搜尋、複製或匯出內容。
- 「服務與存取」新增 GitHub 存取權杖設定，支援隱藏／顯示權杖及前往建立權杖；外掛商店遇到 GitHub API 流量限制時可直接前往設定。
- 「模型與請求」新增「啟用冷卻」開關；缺少冷卻設定時預設關閉，已有明確設定保持不變。

## 優化

- OAuth 登入卡片顯示已儲存的帳號、數量與停用狀態，支援前往憑證檔案查看；授權成功後自動重新整理帳號清單，方便管理多個帳號。
- 將「重試與冷卻」設定移至「模型與請求」，同步調整設定搜尋定位與寬螢幕版面。
- 隨附 CLIProxyAPI 核心升級至 v8.0.24。

## 修復

- 修正 OAuth 授權提示，明確區分新增帳號與重新登入既有帳號；重新登入會更新該帳號憑證，不再提示每次授權都會新增帳號。
- 修復啟動時冷卻設定可能被舊的介面設定或範本預設值覆蓋的問題，保留使用者明確開啟或關閉的選擇。
