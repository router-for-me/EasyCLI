## 新機能

- サイドバーにプライバシーモードを追加しました。画面内のアカウントのメールアドレス、アカウント ID、プロジェクト ID をマスクし、設定を保存します。表示のみが対象で、リクエスト、検索、コピー、エクスポートの内容は変わりません。
- 「サービスとアクセス」に GitHub アクセストークンの設定を追加しました。トークンの表示切り替えと作成ページへのリンクに対応し、プラグインストアで GitHub API のレート制限が発生した際は、この設定へ直接移動できます。
- 「モデルとリクエスト」に「クールダウンを有効化」スイッチを追加しました。設定がない場合はデフォルトで無効になり、既存の明示的な設定は維持されます。

## 改善

- OAuth ログインカードに保存済みアカウント、アカウント数、無効化状態を表示し、認証情報ファイルへのリンクを追加しました。認証成功後はアカウント一覧を自動更新し、複数アカウントを管理しやすくしました。
- 「再試行とクールダウン」を「モデルとリクエスト」に移動し、設定検索の移動先とワイド画面のレイアウトを調整しました。
- 同梱の CLIProxyAPI コアを v8.0.24 に更新しました。

## 修正

- OAuth の認証メッセージを修正し、新規アカウントの追加と既存アカウントへの再ログインを区別しました。再ログインでは既存の認証情報を更新し、毎回新しいアカウントが追加されるという誤った案内を解消しました。
- 起動時に古い GUI 設定やテンプレートのデフォルト値が明示的なクールダウン設定を上書きする可能性がある問題を修正しました。ユーザーが選択した有効・無効の設定を維持します。
