- VS Code Copilot 配置支持写入全部可用模型，并按模型能力设置上下文窗口和图片输入；缺少输入类型信息时默认启用图片输入。
- 完善模型能力信息识别，兼容更多输入类型和输出上限字段，并将输入类型及最大输出 Token 数同步到 OpenClaw 配置。

## 新增

- 新增暖砂、石墨、午夜蓝和樱语红粉主题，支持分别设置浅色与深色主题，并随系统外观自动切换。
- 新增 Codex Business 账户个人支出额度展示，支持查看已用额度、总额度、剩余比例及重置时间。
- 新增 Codex CLI app-server 重启功能。
- 新增 VS Code Copilot 配置支持。
- 新增实验性的上下文编辑功能。

## 优化

- 优化侧边栏“外观”入口，简化按钮底色、边框和图标，使其与周边控件更加协调。
- 内核升级时先完成下载与解压，再停止运行中的代理，缩短服务中断时间；新版本启动失败时支持回滚到旧版本。
- 优化 Codex CLI 服务重启体验：等待运行中的任务结束时，页面其他操作仍可使用，并显示等待提示，避免重复重启。
- 启动时检查更新或手动检查版本时，同步刷新 Codex 模型目录；目录下载失败时继续使用当前配置，不影响版本检查。
- 同步更新内置 Codex 模型模板及默认参数；模型目录更新或应用重启后，保留用户已保存的自定义配置。
- 简化模型配置的默认值操作，统一使用“使用默认值”入口，恢复后点击保存生效。

## 修复

- 修复内核升级重试可能覆盖旧版本回滚备份的问题。
- 修复 macOS 更新过程中 DMG 弹出命令可能长时间卡住的问题，并完善超时后的子进程及临时目录清理。
- 修复主题启动时的显示与已保存主题的迁移问题，统一各页面背景表现。
- 配置 Codex API 密钥且未手动选择图片生成策略时，默认使用 `chat` 模式；保留用户手动保存的策略，避免重启后被默认值覆盖。
- 修复部分 Codex Business 账户返回个人支出额度时，额度查询提示无法识别数据的问题。
