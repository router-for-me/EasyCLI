## 新機能

- 有効なプラグインが提供するページへの入口をサイドバーに追加しました。アプリ内で直接開くことができ、戻る、再読み込み、ブラウザーで開く操作に対応しています。

## 改善

- プラグインストアの更新時に、公開 GitHub リポジトリの最新リリースを直接取得するようにし、キャッシュによるバージョン情報の反映遅延を軽減しました。
- VS Code Copilot の設定に、利用可能なすべてのモデルを登録するようにしました。各モデルの能力に応じてコンテキストウィンドウと画像入力を設定し、入力形式の情報がない場合は画像入力を既定で有効にします。
- モデルの能力情報の認識を改善し、より多くの入力形式や出力上限のフィールドに対応しました。入力形式と最大出力トークン数も OpenClaw の設定に反映します。

## 修正

- macOS で署名済みのコアがネイティブプラグインを読み込めない問題を修正しました。
- Codex モデルカタログの更新時に速度ティアが失われる場合や、カタログファイルの変更がすぐに反映されない問題を修正しました。
- 一部のテーマでボタン、入力欄、ドロップダウンのスタイルが統一されない問題と、開いているメニューにテーマの切り替えが反映されない問題を修正しました。
- アプリのバージョン番号が画面に正しく表示されない問題を修正しました。
- ページを切り替えた後に Codex CLI の再起動に関する表示が残ったり、消えたりする問題を修正しました。
- クライアント設定の書き込み時にシンボリックリンクの検証を強化し、入れ子の設定リンクが設定構造のルートディレクトリを指すことを防ぐようにしました。

## 過去の主な更新

## 新機能

- 暖砂、グラファイト、ミッドナイトブルー、桜のテーマを追加しました。ライトモードとダークモードにそれぞれテーマを設定し、システムの外観に合わせて自動的に切り替えられます。
- Codex Business アカウントの個人の支出上限を表示できるようになりました。使用済みクレジット、上限、残りの割合、リセット時刻を確認できます。
- Codex CLI の app-server を再起動する機能を追加しました。
- VS Code Copilot の設定に対応しました。
- 実験的なコンテキスト編集機能を追加しました。

## 改善

- サイドバーの外観ボタンの背景、枠線、アイコンを簡素化し、周囲の操作ボタンと調和するデザインにしました。
- コアの更新時は、ダウンロードと展開が完了してから実行中のプロキシを停止するようにし、サービスの中断時間を短縮しました。新しいバージョンの起動に失敗した場合は、以前のバージョンにロールバックできます。
- Codex CLI サービスの再起動を改善しました。実行中のタスクの終了を待つ間もページのほかの操作を利用でき、待機中の表示と重複した再起動の防止に対応しました。
- 起動時の更新確認や手動でのバージョン確認に合わせて、Codex モデルカタログも更新するようになりました。カタログのダウンロードに失敗した場合も、現在の設定を使用してバージョン確認を続行します。
- 内蔵の Codex モデルテンプレートと既定のパラメーターを更新しました。保存済みのカスタム設定は、カタログの更新やアプリの再起動後も保持されます。
- モデル設定を既定値に戻す操作を「既定値を使用」に統一しました。復元した値は保存すると適用されます。

## 修正

- コアの更新を再試行した際に、以前のバージョンのロールバック用バックアップが上書きされる可能性がある問題を修正しました。
- macOS の更新中に DMG の取り出しコマンドが長時間停止する問題を修正し、タイムアウト後の子プロセスと一時ディレクトリのクリーンアップを改善しました。
- 起動時のテーマ表示と保存済みテーマの移行に関する問題を修正し、各ページの背景を統一しました。
- Codex API キーが設定され、画像生成ポリシーを手動で選択していない場合は、既定で `chat` モードを使用するようにしました。手動で保存したポリシーは保持され、再起動時に既定値で上書きされません。
- 一部の Codex Business アカウントで個人の支出上限が返された際に、使用枠の取得でデータを認識できないエラーが表示される問題を修正しました。
