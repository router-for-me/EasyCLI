## 優化

- 優化側邊欄「外觀」入口，簡化按鈕底色、邊框和圖示，使其與周邊控制項更加協調。
- 核心升級時先完成下載與解壓縮，再停止執行中的代理，縮短服務中斷時間；新版本啟動失敗時支援回復至舊版本。
- 優化 Codex CLI 服務重新啟動體驗：等待執行中的任務結束時，頁面其他操作仍可使用，並顯示等待提示，避免重複重新啟動。
- 啟動時檢查更新或手動檢查版本時，同步更新 Codex 模型目錄；目錄下載失敗時繼續使用目前設定，不影響版本檢查。
- 同步更新內建 Codex 模型範本及預設參數；模型目錄更新或應用程式重新啟動後，保留使用者已儲存的自訂設定。
- 簡化模型設定的預設值操作，統一使用「使用預設值」入口，還原後點擊儲存生效。

## 修復

- 修復核心升級重試可能覆寫舊版本回復備份的問題。
- 修復 macOS 更新過程中 DMG 退出指令可能長時間卡住的問題，並完善逾時後的子處理程序及暫存目錄清理。
- 修復主題啟動時的顯示與已儲存主題的移轉問題，統一各頁面背景表現。
- 設定 Codex API 金鑰且未手動選擇圖片生成策略時，預設使用 `chat` 模式；保留使用者手動儲存的策略，避免重新啟動後被預設值覆寫。
- 修復部分 Codex Business 帳戶回傳個人支出額度時，額度查詢提示無法辨識資料的問題。
