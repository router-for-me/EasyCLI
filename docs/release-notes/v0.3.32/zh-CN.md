## 新增

- 请求记录新增错误详情复制按钮，折叠和展开状态下都可一键复制，方便排查问题和提交反馈。

## 优化

- API 服务商高级设置按“模型规则”“连接与路由”“请求行为”分组，便于查找和配置。
- 精简使用记录筛选项，保留时间、模型、来源、密钥和结果筛选；请求列表默认展示请求密钥信息，优先显示备注。
- 调整 Windows 自动启动 CLI 的方式，通过持久 PowerShell 会话启动 Claude Code 等客户端，保留工作目录和环境变量设置，改善直接启动时的终端兼容性（[#393](https://github.com/router-for-me/EasyCLIProxyAPI/issues/393)）。

## 修复

- 修复使用记录筛选菜单受页面容器影响而错位或被裁剪，以及长菜单滚动后回到顶部的问题；窗口缩放和父容器滚动时保留菜单滚动位置（[#396](https://github.com/router-for-me/EasyCLIProxyAPI/issues/396)）。
- 修正用量概览 TPS 的计算方式，改为有效请求生成速度的算术平均值。
- 修复凭据和 API 服务商来源备注解析不完整的问题，并将请求密钥标签与上游来源区分，避免混用备注。
- 修复新增密钥或修改备注后筛选列表未及时更新的问题，支持手动刷新和定期更新，并保留当前密钥选择。
- 修复 Oh My Pi 的 API 密钥仅依赖启动时环境变量的问题，改为写入 `models.yml`，使手动从终端启动时也能使用已配置的密钥。
