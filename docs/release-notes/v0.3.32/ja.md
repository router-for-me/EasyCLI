## 新機能

- 「モデルとリクエスト」で Antigravity のシステムプロンプトの機密語リストが空の場合、ページを開くか更新すると `Claude`、`GPT-5`、`GPT-6`、`Codex`、`Anthropic` が事前入力されます。「保存」をクリックすると適用されます。既存の空でないリストは変更されません。
- リクエスト記録のエラー詳細にコピーボタンを追加しました。折りたたみ表示と展開表示のどちらでもコピーでき、問題の調査や報告に利用できます。

## 改善

- API プロバイダーの詳細設定を「モデルルール」「接続とルーティング」「リクエスト動作」に分類し、設定を探しやすくしました。
- 使用記録のフィルターを期間、モデル、ソース、API キー、結果に整理しました。リクエスト一覧では、リクエストキーの情報を標準で表示し、メモがある場合は優先して表示します。
- Windows の CLI 自動起動を変更しました。Claude Code などのクライアントを終了後も開いたままの PowerShell セッションから起動し、作業ディレクトリと環境変数の設定を維持することで、直接起動時の端末互換性を改善します（[#393](https://github.com/router-for-me/EasyCLIProxyAPI/issues/393)）。

## 修正

- 使用記録のフィルターメニューがページ内のコンテナーによってずれたり切れたりする問題と、長いメニューをスクロールすると先頭に戻る問題を修正しました。ウィンドウのサイズ変更や親コンテナーのスクロール時も、メニューのスクロール位置を維持します（[#396](https://github.com/router-for-me/EasyCLIProxyAPI/issues/396)）。
- 用量概要の TPS を、有効なリクエストごとの生成速度の算術平均で計算するよう修正しました。
- 認証情報と API プロバイダーのソースメモが正しく取得できない問題を修正しました。また、リクエストキーのラベルと上流ソースを分離し、メモの混同を防ぎます。
- キーの追加やメモの変更がフィルター一覧に反映されない問題を修正しました。手動更新と定期更新で選択肢を更新し、選択中のキーは維持します。
- Oh My Pi の API キーが起動時の環境変数に依存していた問題を修正しました。キーを `models.yml` に保存することで、端末から手動で起動した場合も設定済みのキーを使用できます。
