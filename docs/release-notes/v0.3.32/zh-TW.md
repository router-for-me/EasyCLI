## 新增

- 請求記錄新增錯誤詳情複製按鈕，收合與展開狀態下皆可一鍵複製，方便排查問題與提交回饋。

## 優化

- API 服務商進階設定依「模型規則」「連線與路由」「請求行為」分組，方便查找與設定。
- 精簡使用記錄篩選項目，保留時間、模型、來源、金鑰與結果篩選；請求清單預設顯示請求金鑰資訊，優先顯示備註。
- 調整 Windows 自動啟動 CLI 的方式，透過持續開啟的 PowerShell 工作階段啟動 Claude Code 等用戶端，保留工作目錄與環境變數設定，改善直接啟動時的終端機相容性（[#393](https://github.com/router-for-me/EasyCLIProxyAPI/issues/393)）。

## 修復

- 修復使用記錄篩選選單受頁面容器影響而錯位或被裁切，以及長選單捲動後回到頂端的問題；調整視窗大小與捲動父容器時保留選單捲動位置（[#396](https://github.com/router-for-me/EasyCLIProxyAPI/issues/396)）。
- 修正用量概覽 TPS 的計算方式，改為有效請求生成速度的算術平均值。
- 修復憑證與 API 服務商來源備註解析不完整的問題，並區分請求金鑰標籤與上游來源，避免混用備註。
- 修復新增金鑰或修改備註後篩選清單未及時更新的問題，支援手動重新整理與定期更新，並保留目前選取的金鑰。
- 修復 Oh My Pi 的 API 金鑰僅依賴啟動時環境變數的問題，改為寫入 `models.yml`，讓手動從終端機啟動時也能使用已設定的金鑰。
