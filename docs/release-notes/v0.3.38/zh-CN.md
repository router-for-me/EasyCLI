- 新增暖砂、石墨、午夜蓝和樱语红粉主题，支持分别设置浅色与深色主题，并随系统外观自动切换。

## 优化

- 优化侧边栏“外观”入口，简化按钮底色、边框和图标，使其与周边控件更加协调。
- 内核升级时先完成下载与解压，再停止运行中的代理，缩短服务中断时间；新版本启动失败时支持回滚到旧版本。
- 优化 Codex CLI 服务重启体验：等待运行中的任务结束时，页面其他操作仍可使用，并显示等待提示，避免重复重启。

## 修复

- 修复内核升级重试可能覆盖旧版本回滚备份的问题。
- 修复 macOS 更新过程中 DMG 弹出命令可能长时间卡住的问题，并完善超时后的子进程及临时目录清理。
- 修复主题启动时的显示与已保存主题的迁移问题，统一各页面背景表现。
- 配置 Codex API 密钥且未手动选择图片生成策略时，默认使用 `chat` 模式；保留用户手动保存的策略，避免重启后被默认值覆盖。
