## 部分历史更新

## 新增

- 新增侧边栏插件页面入口，可直接在应用内打开已启用插件提供的页面，并支持返回、刷新及在浏览器中打开。
- 新增暖砂、石墨、午夜蓝和樱语红粉主题，支持分别设置浅色与深色主题，并随系统外观自动切换。
- 新增 Codex Business 账户个人支出额度展示，支持查看已用额度、总额度、剩余比例及重置时间。
- 新增 Codex CLI app-server 重启功能。
- 新增 VS Code Copilot 配置支持。
- 新增实验性的上下文编辑功能。

## 优化

- 刷新插件商店时直接查询公开 GitHub 仓库的最新发布版本，减少缓存造成的版本信息延迟。
- VS Code Copilot 配置支持写入全部可用模型，并按模型能力设置上下文窗口和图片输入；缺少输入类型信息时默认启用图片输入。
- 完善模型能力信息识别，兼容更多输入类型和输出上限字段，并将输入类型及最大输出 Token 数同步到 OpenClaw 配置。
- 优化侧边栏“外观”入口，简化按钮底色、边框和图标，使其与周边控件更加协调。
- 内核升级时先完成下载与解压，再停止运行中的代理，缩短服务中断时间；新版本启动失败时支持回滚到旧版本。

## 修复

- 修复 macOS 签名内核无法加载原生插件的问题。
- 修复 Codex 模型目录更新后速度档位可能丢失、目录文件变更未及时生效的问题。
- 修复部分主题下按钮、输入框和下拉菜单的样式不一致，以及菜单展开时切换主题未同步更新的问题。
- 修复应用版本号无法在界面中正常显示的问题。
- 修复切换页面后 Codex CLI 重启提示残留或丢失的问题。
- 加强客户端配置写入时的符号链接校验，防止嵌套配置链接指向配置结构的根目录。
